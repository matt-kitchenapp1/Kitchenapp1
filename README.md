# My Kitchen Planner

A personal meal planning app for your family.

## Setup on Vercel (5 minutes)

1. Go to https://vercel.com and sign up for a free account
2. Click "Add New Project"
3. Choose "Upload" (you don't need GitHub)
4. Drag and drop this entire folder (or zip it and upload)
5. Leave all settings as default and click "Deploy"
6. In about 60 seconds you'll get a URL like `my-kitchen-planner.vercel.app`
7. Bookmark that URL on both phones!

## First time in the app

1. Tap the **🔑 Set API Key** button (top right)
2. Get a free API key from https://console.anthropic.com → API Keys
3. Paste it in and save
4. Go to **Family** tab and set your names
5. Go to **Settings** and set your week start day
6. Start adding recipes!

## Notes

- All data saves automatically to your browser's local storage
- The API key is stored locally in your browser only
- Both family members should set the API key on their own device
- Recipes, plans and shopping lists sync via the shared storage system
